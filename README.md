Proyecto FidnessApp (Cliente-Servidor)

Este proyecto es una aplicacion en Java que simula un sistema de rutinas de ejercicio.

Incluye:

* Login basico
* Menu principal
* Ver ejercicios
* Crear rutina
* Exportar rutina a archivo txt

Se uso:

* Programacion orientada a objetos (clases, herencia, polimorfismo)
* Colecciones (ArrayList)
* Manejo de excepciones
* Sockets (cliente-servidor)
* Multihilos
* Interfaz grafica con JFrame (Swing)

Notas:

* El login es simulado para efectos del avance
* La exportacion genera un archivo rutina.txt
* La interfaz se hizo manualmente sin diseñador
